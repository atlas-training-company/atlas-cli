# Review training and progress deliberately

Read guidance by ID with the Atlas `knowledge` tool (`get` action) or `atlas knowledge get ID`. Start with `guides/coaching-context`, then `guides/progression-decisions` and `guides/stimulus-fatigue`; `guides/review-adaptation` and `guides/history-metrics` explain Atlas history.

Read the active program, last complete week's `weekly-summary` and relevant exercise history first.

1. Identify the exercise, prescription and comparable exposures. Separate completed from planned, skipped or warm-up sets.
2. State what the data can establish. Unknown effort, units or execution blocks claims that depend on them, not the valid observations.
3. Compare clean reps and load at similar execution and intended effort. Select progress, repeat, reduce demand or gather missing data. Use the program's progression rule when it has one; otherwise propose one.
4. Change one lever when possible. Explain the trigger, increment, fallback if it overshoots, and what to watch next.
5. Check a repeated decline against context (adherence, setup, sleep). Use `guides/progression-decisions` to choose today's demand or a longer adjustment, and `guides/stimulus-fatigue` for exercise and set tradeoffs. Missing logs and one hard day do not establish a plateau.

Return observed performance, data gaps, per-exercise recommendation, rationale and what to log next. Separate advice from saved changes. Never infer effort that was not recorded, convert old RIR/RPE labels to Effort % by guesswork, or raise every load because a session is marked completed. Save changed prescriptions only when the athlete asked or approves.

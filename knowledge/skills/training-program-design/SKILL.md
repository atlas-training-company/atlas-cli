# Build a program and choose a split

Read guidance by ID with the Atlas `knowledge` tool (`get` action) or `atlas knowledge get ID`. Start with `guides/coaching-context`; use `guides/program-modes`, `guides/split-decisions`, `guides/stimulus-fatigue` and, to save, `guides/program-authoring`.

From Atlas, establish goals, the current program and block, actual history, training days (`days_per_week`, `preferred_days`), session length (`session_minutes`, `session_minutes_by_day`), styles (`preferred_styles`, `avoided_styles`), equipment per location and competing demands. Ask only for what is missing.

1. Identify the binding constraint; preserve a working program unless the change solves it. Choose the program mode.
2. Compare schedules by coverage, recovery, session quality and missed-day behavior. A split names how work is spread, not how well it works.
3. Set a starting dose from current completed work and tolerability, or mark it a conservative trial. Separate direct and indirect muscle work. Research averages are not mandatory personal volume (`volume`, `frequency`, `evidence/2026-10-12-coaching-source-checks`).
4. Specify exercise roles, sets, one exact rep count, one exact Effort %, a weight and rest for every set (no ranges), progression criteria and a review point. Set Effort by exercise type: about 90% only for top sets and the last isolation set, 80–85% for most other work (85% counts as hard; aim for 80%). Respect style preferences (circuits, supersets) where they fit the goal and say what one costs. Say how missed sessions roll forward; when a session runs heavy, trim sets before cutting weight.
5. Score every session for stacking; keep it under the caps: no two high-fatigue lifts on the same area in a day. Check its time limit, equipment and conditioning. Keep growth, maintenance and strength-test goals distinct.

For a split-choice question, give a concise recommendation, the nearest alternative and a missed-day rule. For a full program, also give session outlines, progression and recovery rules, evidence limits and review criteria. Save it as a draft when the athlete wants it saved (`guides/program-authoring`); activate or schedule it only when they ask.
